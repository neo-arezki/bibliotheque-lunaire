# Devlog

Chronique du développement de **La Bibliothèque Lunaire**.

Ce fichier conserve les grandes étapes du projet, ses orientations et les décisions qui ont marqué son évolution. Il ne remplace ni l’historique Git ni la documentation technique.

---

## v0.0.1 — 25/07/2026

Première exécution native de l’application.

Stack technique validée :

* Rust
* Tauri v2
* Vite
* TypeScript
* Git
* GitHub

Le projet compile et la première fenêtre native s’ouvre correctement avec :

```bash
npm run tauri dev
```

L’environnement de développement est opérationnel.

La construction de la Bibliothèque Lunaire peut commencer.
