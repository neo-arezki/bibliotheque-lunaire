# 01 - Game Design Document

Version : 1.0

## Plateforme

Plateforme principale : Android.
Fonctionnement hors ligne.
Une version Windows pourra être envisagée ultérieurement.

## Boucle principale

Entrer dans la Bibliothèque.
Explorer.
Étudier.
Prendre soin du lieu.
Quitter.
Revenir.

## Architecture

La Bibliothèque est une base lunaire.

Espaces validés :
- Salle principale
- Scriptorium
- Serre
- Observatoire

Les nouvelles ailes sont découvertes par des portes.

## Navigation

Défilement vertical naturel.
Le joueur explore le bâtiment plutôt que des menus.

## O.G.

O.G. n'est pas un avatar.
Elle vit dans la Bibliothèque :
- lecture
- écriture
- contemplation
- jardinage
- déplacements

## Serre

La serre se développe lentement.
Sa croissance accompagne la reconstruction de la personne.

## Observatoire

Lieu de silence, de respiration et de contemplation de la Terre.

## Direction sonore

Le monde répond.
Il ne récompense pas.

Les sons sont sobres, physiques et signifiants.
