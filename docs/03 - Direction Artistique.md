# 02 - Direction Artistique

Version : 1.0

## Intention

La Bibliothèque lunaire doit évoquer un lieu habité depuis longtemps, où chaque objet possède une histoire.

## Principes

- Sobriété avant spectaculaire.
- Matières naturelles : bois, pierre, papier, métal.
- Lumière douce et contrastes limités.
- Peu d'éléments, mais chacun est signifiant.

## Architecture

La Bibliothèque est une base lunaire.

Espaces validés :
- Salle principale
- Scriptorium
- Serre
- Observatoire

Les nouvelles ailes sont découvertes par des portes.

## O.G.

O.G. est une habitante, jamais un curseur incarné.
Elle peut être vue en train de lire, écrire, arroser la serre ou contempler la Terre.

## Symbolique

Livre : mémoire.
Porte : nouveau chapitre.
Serre : reconstruction.
Observatoire : contemplation.
Terre : continuité.
